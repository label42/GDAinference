# Target example: group cloud

The four impact points compared with the
[Target](https://label42.github.io/GDAinference/reference/Target.md)
reference cloud in the combinatorial typicality test of Le Roux,
Bienaise and Durand (2019, chapter 3). The book reports a Mahalanobis
distance `D = 0.964` and a combinatorial p-value of `9 / 210 = 0.043`.

## Usage

``` r
Target_group
```

## Format

A data frame with 4 rows and 2 numeric columns (`X`, `Y`); row names are
the point identifiers `c1`...`c4`.

## Source

Le Roux, B., Bienaise, S. & Durand, J.-L. (2019). *Combinatorial
Inference in Geometric Data Analysis*. Chapman & Hall/CRC.
