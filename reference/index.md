# Package index

## Typicality tests

Exact combinatorial inference tests for the typicality of a mean point
in a geometric (GDA) cloud (Le Roux, Bienaise & Durand 2019, chapters
3–4).

- [`typicality_comb()`](https://label42.github.io/GDAinference/reference/typicality_comb.md)
  : Combinatorial typicality test for a mean point
- [`typicality_byvar()`](https://label42.github.io/GDAinference/reference/typicality_byvar.md)
  : Combinatorial typicality test for every category of a variable
- [`typicality_geom()`](https://label42.github.io/GDAinference/reference/typicality_geom.md)
  : Geometric typicality test for a mean point

## Compatibility with GDA packages

Extract principal coordinates from the result objects of the common GDA
packages, so the tests work whatever the upstream tool.

- [`get_coord()`](https://label42.github.io/GDAinference/reference/get_coord.md)
  : Extract principal coordinates from a GDA result
