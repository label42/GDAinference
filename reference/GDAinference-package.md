# GDAinference: Combinatorial Inference in Geometric Data Analysis

Exact combinatorial (permutation) inference tests for Geometric Data
Analysis (GDA). The package implements the multidimensional typicality
and homogeneity tests introduced by Le Roux, Bienaise and Durand (2019,
"Combinatorial Inference in Geometric Data Analysis", Chapman &
Hall/CRC). Tests operate on the principal coordinates produced by common
GDA methods and integrate natively with the 'FactoMineR', 'GDAtools' and
'ade4' packages, as well as with plain coordinate matrices. Each test
returns a p-value from the combinatorial distribution of a
Mahalanobis-type statistic, together with a compatibility region. Unlike
the chi-squared approximations sometimes used in practice, the tests are
exact (exhaustive enumeration when feasible, Monte Carlo otherwise).
