# Student example

The "Student" didactic data set used for the one-dimensional geometric
typicality test in Le Roux, Bienaise and Durand (2019, section 4.4): 10
measurements on a single variable.

## Usage

``` r
Student
```

## Format

A data frame with 10 rows and 1 numeric column (`X`); row names are the
subject identifiers `s1`...`s10`.

## Source

Le Roux, B., Bienaise, S. & Durand, J.-L. (2019). *Combinatorial
Inference in Geometric Data Analysis*. Chapman & Hall/CRC.
